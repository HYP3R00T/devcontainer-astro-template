## Usage

Buttons are built with `class-variance-authority` and support variant, size, and `asChild` composition patterns.

## Code

```tsx
import { Button } from "@/components/ui/button";

<Button>default</Button>
<Button variant="outline">outline</Button>
<Button variant="secondary">secondary</Button>
<Button variant="ghost">ghost</Button>
<Button variant="destructive">destructive</Button>
```

## Notes

Use `outline` for lower-emphasis actions, `default` for primary actions, and `ghost` where the surrounding layout already provides enough visual structure.
